# 微信小程序原型

## 打开方式
1. 使用微信开发者工具导入本目录 `wechat-miniprogram/`。
2. 项目 AppID 当前为体验占位配置，开发者需在工具中选择自己的 AppID 或测试模式。
3. 当前页面可离线运行；输入快照仅保存在本机微信存储中。

## 当前能力
- 现场参数录入、基本正值/几何检查和本机保存。
- 用当前裸眼井径、所填钻柱外径与排量计算名义环空流速。
- 清楚标注 ECD、温压流变和携岩模型尚未标定，不输出虚假的工程预测值。
- 样例值来自用户提供的录井图片和文字，部分数据标记为待现场核验。

## 尚未实现
CSV 实际解析、测斜轨迹计算、分段钻具/井眼模型、瞬态起下钻模型、温压相关流变修正、ECD 压耗计算和岩屑运移模型。上线前需要工程模型验证、边界测试与有资质人员审核。此原型不得用于直接下达井控或现场处置指令。
