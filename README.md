# CTS-DEM 钻井携岩仿真与 ECD-CUTtime 计算平台

单文件、离线、零外部资源的钻井工程计算平台（HTML），双击即可在浏览器打开使用，支持在 Windows / 安卓 / 苹果 / 华为手机等设备上运行。

## 功能

- 钻井携岩（岩屑运移）仿真
- ECD（当量循环密度，Equivalent Circulating Density）计算
- CUTtime（岩屑返出/井底清洁时间）计算

## 使用方式

直接双击 `CTS-DEM_钻井携岩仿真与ECD-CUTtime计算平台.html`，用浏览器打开即可，无需安装任何依赖或联网。
